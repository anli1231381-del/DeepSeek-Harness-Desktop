# v0.4.0 Environment, Language, and Work Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the installed app self-checking, bilingual, and explicit about every successful or failed work step.

**Architecture:** Keep the bundled Node/Harness distribution. Add structured environment and execution-step data at the existing runtime boundary, render it in the existing settings and conversation views, and use a small local translation table with no new dependency.

**Tech Stack:** Tauri 2, React 19, TypeScript, Node.js runtime bridge, Node test runner, Playwright.

**Spec:** User-approved v0.4.0 design in the current task.

## Global Constraints

- Windows 10/11 x64; core Node and Harness remain bundled.
- Missing Git gets detection, a one-click Winget attempt, and an official-download fallback.
- Visible work steps may show observable actions and errors, never private model reasoning or secrets.
- Existing saved sessions and string logs remain readable.
