## v0.3.0

这一版把工作入口改成了真正的连续对话界面。打开首页即可发送消息，无需先添加项目；需要处理文件时，可以在同一段对话中关联或切换项目，历史记录会保留，并显示当前真实操作目录。每个项目也可以新建多段独立对话。

新增内容：

- 无项目连续对话，以及项目中途关联和切换。
- 本地 Skill 导入、启用、停用、删除、全局/项目范围和真实加载状态。
- 远程及本地 MCP、JSON 导入、连接测试和工具列表。
- 从公开 GitHub 仓库或目录安装、更新 Skill。
- Git 检测、版本显示和安装引导。
- 右下角 DeepSeek 登录入口，弹层不会覆盖或清除工作对话。
- 内置 DeepSeek 官网加载状态、刷新和网页实例重建，修复空白页面难以恢复的问题。
- 新执行自动捕获文件成果，并可直接打开文件或所在位置。

验证：39 项自动测试全部通过；生产前端和 Rust Release 编译通过；完整 NSIS 安装包已在 D 盘实际安装，并从安装目录完成内置 Harness、连续对话、本机模拟模型、Git 差异和 DeepSeek 官网子窗口端到端测试。

安装包未配置代码签名，Windows 可能显示来源提示。DeepSeek 官网和远程模型调用需要联网；工作模式使用你在设置中保存的 API 配置。
