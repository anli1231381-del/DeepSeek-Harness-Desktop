# Harness 桌面助手 v0.2.0

基于 DeepSeek Harness 的独立桌面应用，不是 DeepSeek 官方产品。适用于 Windows 10/11 x64。

## 下载与安装

普通用户下载 `HarnessDesktop-0.2.0-windows-x64-setup.exe`。内置 Node.js 与 Harness，无需自行安装开发环境；缺少 WebView2 时安装器会联网补齐。Source code 压缩包用于开发，不能直接作为软件运行。

## 本版更新

- 多轮会话、项目分组和独立工作目录，持久保存消息、执行日志和文件成果。
- 执行队列、实时日志、停止执行与取消排队，切换会话保留输入草稿。
- 自动捕获执行期间新增、修改、删除的文件，支持历史文本对比、打开文件和目录。文件后续修改或删除会提示。
- OpenRouter 配置预设、模型列表与模型选择，使用 OpenAI 兼容协议，密钥由 Windows 加密保存。
- 优先使用真实 Harness。启动失败明确标注模拟结果；执行中途失败如实显示错误，保留部分成果。
- 修复历史数据迁移和未完成任务恢复，避免重启后长期显示“进行中”。
- 更新蓝色鲸鱼图标，完善源码构建流程与 GitHub Windows 测试环境。

## 使用与范围

在“设置 → 模型 API → 添加 API”保存服务商、密钥和模型，再点击“使用”。软件不附带 API 额度。

同时执行一个任务。文件成果通过目录前后快照识别，其他程序同期修改的文件也可能被记录。忽略依赖目录和 Git 内部目录；二进制文件或超过 128 KB 的文件不内嵌文本对比。代码默认以记事本打开，文档使用系统关联程序，其他文件定位到资源管理器。

安装包未配置代码签名。安装与真实模型验证记录待更新。
