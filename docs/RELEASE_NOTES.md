# Harness 桌面助手 v0.1.4 · 首个公开版本

一个面向新手的中文 AI 桌面助手：选中项目、描述目标，查看 AI 的工作过程；需要日常聊天时，一键切换到 DeepSeek 官网。

本项目基于 DeepSeek Harness 构建独立桌面界面，不是 DeepSeek 官方产品。当前版本面向 **Windows 10/11 x64**。

## 普通用户下载哪个文件？

下载下方 Assets 中的 **`HarnessDesktop-0.1.4-windows-x64-setup.exe`**，双击安装即可。

安装包内置 **Node.js 和 DeepSeek Harness**，无需预装开发环境。缺少 WebView2 时，安装器会联网补齐。其他源码、许可及校验附件无需安装，也不要将 GitHub 自动生成的 Source code 压缩包当作应用。

## 首发功能

- **工作 / 对话双模式**：一键切换，保留工作草稿和网页会话，切换不会停止任务。
- **官网对话**：应用内打开 DeepSeek 官网，自行登录，无需配置 API；提供刷新和浏览器打开入口。
- **可视化工作过程**：项目选择、任务执行记录、结果回复与 Git 文件差异预览。
- **模型 API 配置**：DeepSeek、OpenAI、Anthropic 预设与自定义兼容服务，支持模型列表获取和模型切换。
- **运行环境管理**：内置运行环境，支持检测本机已有 Harness 配置。
- **自由主题色**：浅色、深色、跟随系统，自由色盘与 HEX 输入，自动保存偏好。

## 安装后怎么开始？

**只想聊天：** 打开应用，点击左侧 **对话**，登录自己的 DeepSeek 账号。

**想让 AI 处理项目：** 在 **设置 → 模型 API** 添加自己的密钥并选择模型，保存后点击 **使用**；验证连接，再回到首页选择项目、描述目标并开始任务。

## 当前范围

- 软件不附带 API 额度，官网账号与工作模式的 API 配置分别管理。
- Git 差异预览需要 Git；具体项目所需的 Python、Java、编译器等工具仍需另外准备。
- 同时运行一个工作任务，暂不支持停止后的断点续跑。
- 当前安装包未配置代码签名；全新 Windows 虚拟机上的首次安装仍待验证。

已验证 Windows 实际安装、内置环境启动、API 配置、工作任务执行、官网登录页加载和模式切换。模型测试使用本机模拟 API，未使用用户真实密钥；未代用户登录官网，也未验证所有远程模型和第三方登录方式。
