## v0.3.1

这一版重新整理了工作首页，让连续对话成为默认使用方式。

- 用户消息靠右显示，助手回答直接显示正文，不再添加“AI”标签。
- 每轮完成后显示真实耗时；点击耗时可展开真实执行事件、工具调用和日志。
- 输入区改为固定卡片，提供 Skills、MCP、停止执行和发送入口。
- 无需关联项目即可对话；关联或切换项目后继续保留同一段聊天记录。
- DeepSeek 登录改为右下角弹出卡片，工作模式 API 设置保持独立。
- 主题色色盘同步影响页面、侧栏、卡片、边框、选中状态和按钮。
- 修复回答中 Markdown 粗体和列表符号显示不正确的问题。
- 保留 Skills、MCP、GitHub 扩展安装、Git 检测、OpenRouter 和文件成果捕获功能。

验证：39 项自动测试与生产构建通过；完整 Windows 安装包在发布前重新构建并安装验证。

安装包未配置代码签名，Windows 可能显示来源提示。DeepSeek 官网及远程模型调用需要联网；工作模式使用“设置”中保存的 API 配置。
